# 写作规范

本目录是 CS 与 LLM 方向的学习教程。格式、frontmatter、图片、公式与图表的通用约定见上层 `articles/AGENTS.md`，这里只写本栏目的读者与内容取向。

## 读者

有一定数学功底的计算机学生：默认掌握线性代数、概率论与微积分基础，能读代码，不必从"什么是矩阵"讲起；工程与论文里的行话第一次出现时仍需解释。

## 内容

- 以理解为目标：先讲直觉与动机，再给形式化定义；公式服务于解释，不堆推导。
- 算法优先写伪代码或最短可读的实现代码，不放整段框架样板。
- 抽象结构（数据流、模块关系、状态转移、时序）优先画图，不用整段文字铺陈。
- 不确定的事实（论文数字、版本行为）标注出处或注明存疑。

## 系列组织

- 按系列建目录，一个目录放一个系列；目录名按是否需要出现在 URL 里决定加不加括号。
- 系列内按阅读顺序编 `index`。
