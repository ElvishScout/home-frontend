# 文章写作规范

`articles/` 下所有文章共用的约定。栏目目录里的 `AGENTS.md` 在此之上补充该栏目的读者与内容取向，两者冲突时以更靠近文章的那份为准。

## 目录与 URL

- 文件名即 URL 末段，用小写横线（kebab-case），改名等于换链接。
- 括号目录在不改变 URL 的前提下做分组，栏目与系列都这样放；普通目录会进入 URL。
- 同一相对路径只在一个栏目里用，不同括号目录下的同名路径会互相覆盖。

## 文件

- 格式 `.md`；需要内嵌自定义组件时用 `.mdx`，组件先在 `mdx-components.tsx` 注册。

## Frontmatter

```markdown
---
title: 标题
index: 1
---
```

- `title` 非必须：不写时取正文第一个 `#` 的文本。
- `index` 是同目录内的阅读序号（整数，同目录不可重复，重复会让构建失败）。同目录中带 `index` 的文章按序号串成上一篇 / 下一篇导航，不写则不参与导航。

## 图片

- 用 markdown 语法 `![说明](./graph.png)`，不写裸 `<img>`。
- 图片与文章同目录（可建 `images/` 子目录），随文章一起提交，不放 `public/`。
- 相对路径以文章文件为基准，`./`、`../` 都可用。
- `alt` 必填，它既是无障碍名称，也可能被用作图注。

## 公式

- 行内 `$...$`，独立成行 `$$...$$`。
- mermaid 的标签里同样可以写公式，用 `$$...$$` 包起来，如 `h1["$$h_1$$"]`。

## Mermaid

- 围栏代码块标 `mermaid` 即可。
- 节点文案简短，长句放正文；一张图只讲一件事，讲不清就拆成两张。
- 复杂流程用 `flowchart TD`，模块拓扑用 `flowchart LR`，交互时序用 `sequenceDiagram`。

## 不发布的文件

- `AGENTS.md` 与 `CLAUDE.md` 在 `next.config.ts` 的 `exclude` 名单里，不会被注册成文章。新增同类说明文件时同步加入这份名单。
